# 学习助手聊天会话

## 操作

- **新建聊天**：开始独立的一段对话，首条提问自动成为聊天名称。
- **聊天历史**：点击列表切换，搜索框按聊天名称筛选；手机使用页面右上方的“聊天历史”。
- **重命名**：列表中的笔形按钮修改名称，手动名称不会被后续提问覆盖。
- **删除**：列表中的垃圾桶按钮打开确认框，确认后删除该会话及全部消息。取消不会删除；删除无法在页面恢复。
- **继续追问**：输入框 Enter 发送，Shift + Enter 换行。上一条失败时可以重试；回复整理期间可切换到其他聊天。
- **查看早期记录**：较长聊天先显示最近 50 条，顶部“加载更早的消息”读取上一页。

消息及名称自动保存到服务器数据库。浏览器只保存最近打开的会话编号，刷新或重新登录可以恢复聊天；输入中的草稿在当前页面按会话保存，刷新后不保留。

## 上下文

每次提问只使用当前会话的历史消息。最近 20 条进入模型请求，单条至多 12,000 字符，合计至多 48,000 字符；更早的内容仍在历史中，可以引用或概括后继续提问。个人错题、知识点、学习统计和相关资料仍可用于教学与复盘。

从错题页面进入助手会新建关联该错题的聊天，后续追问继续使用关联资料。软删除错题后聊天保留，后续不再读取已删除题目。

## 升级与数据

Flyway V10 新建 `chat_conversations`，为 `chat_messages` 添加必填 `conversation_id`。旧消息全部迁入“此前的学习对话”，原消息编号、内容、引用、检索状态及时间保留。

会话删除通过外键级联删除消息；生成结果保存前检查会话和本次请求，已删除会话的迟到回复不会重新建档。同一会话同时提交下一条问题返回冲突，不同会话可分别生成。服务异常中断后租约到期可重试，不需要清空历史。

更新前按部署说明备份数据库。聊天随 PostgreSQL 备份和恢复，不依赖单台浏览器的本地存储。
