# 知序前端设计与核验

用户确认首页的视觉方向后，本轮将其延展到全部前端页面；随后按用户补充要求，去掉内容区重复的栏目标题。栏目名称仍供辅助技术识别，界面直接呈现日期、数量、筛选和操作。录入、编辑、错题复盘及文章标题保留。

## 设计依据

使用现有 `frontend-app-builder`、`frontend-design`、`frontend-skill` 和 `frontend-testing-debugging` 技能。先生成列表、阅读、聊天和登录的完整屏幕参考，再按同一套规则实现。参考图仅用于设计核对；界面文字、输入框、图表、按钮和列表全部由 Vue 原生渲染。

- 已确认的首页方向：[首页参考](design/zhixu-overview-concept.png)。
- 扩展参考：[错题列表](design/zhixu-questions-concept.png)、[阅读](design/zhixu-reading-concept.png)、[聊天](design/zhixu-chat-concept.png)、[登录](design/zhixu-login-concept.png)。
- 图片资产复用首页的纸页山峦与书本。登录页按双栏构图裁切，手机改为顶部短幅。只用边缘透明蒙版融入底色，没有叠加色罩。

| 角色 | 浅色值 | 使用方式 |
| --- | --- | --- |
| 页面 | `#ffffff` | 纸白工作区、开放的内容布局 |
| 导航 | `#edf5fb` | 淡蓝侧栏与推荐阅读条带 |
| 正文 | `#203449` | 深蓝文字 |
| 辅助文字 | `#64748b` | 来源、日期与状态说明 |
| 分隔 | `#e3eaf0` | 内容行、表格与区块边界 |
| 链接及图表 | `#46749a` | 阅读链接、掌握度与选中状态 |
| 主操作 | `#bf4f2b` | 录入、提交、保存和发送 |

字体在项目内自托管。正文和控件使用 Study Sans，品牌、内容标题、题干预览和数字使用 Study Song Text。深色主题统一由根级语义变量切换，图表从相同变量取得字体与提示框颜色。主操作按钮在两种主题下均为朱红底、白字。

## 页面与代码

| 页面族 | 改动 |
| --- | --- |
| 导航及首页 | 全站共用淡蓝导航、线性图标和选中刻度；页头保留分组、模型及账号；首页以真实日期开场 |
| 错题列表 | 以序号作为扫描线索，题型、难度、题干、实际选项及来源日期排为开放内容行 |
| 录入与编辑 | 题目、作答解析、知识点来源三个编号分区；保存操作固定在滚动区域底部 |
| 错题详情及复习 | 限制正文行宽，保留答案反馈、错因确认、相似题检索与复习安排；读取复习时显示加载状态 |
| 知识点及词语 | 掌握度使用统一蓝色进度；词语突出宋体词目、释义和近反义词详情；收藏使用可读状态与 SVG 图标 |
| 时政及素材 | 文章直接以页面为纸张，保留来源核实、原文链接、标签与分析详情；完成的抓取记录折叠，来源配置移至阅读区之后 |
| 时政响应式 | 大屏初始展示分布图；小窗口和手机先呈现正文，图表可随时展开，手机筛选器使用两行布局，不减少任何数据 |
| 统计与周报 | 开放数字栏、分隔的图表和内容区，取消重复卡片边框；统计数据仍来自实际 API |
| 学习记录及进度 | 记录呈现为时间线；处理状态、失败原因和重试保持原功能 |
| 两个助手 | 对话历史与正文之间只用一条分隔线，用户消息淡蓝、助手回答开放排版；主题提纲保留引用与保存 |
| 登录 | 左侧品牌与书本、右侧账号表单；保留密码显示、主题切换、错误反馈和原鉴权方式 |

`src/style.css` 集中根级字体、颜色和基础语义；`src/workspace.css` 管导航与页头；`src/study-pages.css` 管列表、阅读、表单、指标和登录等页面族；`src/dashboard.css` 保留首页自己的组合。`PageHeader.vue` 管统一操作栏及栏目标题的视觉隐藏。现有 API、路由、数据字段、Markdown / KaTeX 安全渲染、会话管理和原生 dialog 焦点行为沿用。

## 与参考逐图核验

环境没有可调用的 Browser 插件，因此使用项目已有 Playwright Chromium 访问本地真实服务。使用 `view_image` 在同一轮查看参考图与最新浏览器截图；桌面按参考原生尺寸 1448×1086 截图，另检查 1191×668、800px、390px 和 320px。

| 对照点 | 参考证据 | 实现与修正 |
| --- | --- | --- |
| 导航与布局 | 212px 淡蓝侧栏、白色工作区、顶部细分隔 | 从仅首页样式提取为全站导航；小窗口与手机保持当前入口可见 |
| 栏目文案 | 参考图有重复的大栏目名 | 用户明确要求移除，所有栏目名视觉隐藏；首页以日期开场，具体任务与文章标题保留 |
| 字体层次 | 宋体品牌、标题、序号与数字，清晰无衬线控件 | 统一自托管字体与字号；修正词语标题被旧高优先级规则覆盖的问题 |
| 配色及容器 | 白、淡蓝、深蓝及少量橙红，开放内容行 | 根级主题统一；将旧绿色图表及强调色同步为蓝色；减少重复卡片边框 |
| 列表细节 | 序号扫描线、选项及题目元信息 | 按真实题目字段展示；搜索、题型、清空筛选和详情入口均已实际点击验证 |
| 阅读节奏 | 图表之后出现正文，内容层次由排版建立 | 折叠已完成抓取结果；小窗口默认收起分布图，正文更早出现；原文及来源功能保留 |
| 资产融入 | 纸页山峦与书本和淡蓝背景融合 | 复用独立资产，无假 UI 图片；修正手机登录图像顶部的硬接缝 |
| 聊天与窄屏 | 历史栏、连续回答、底部输入区 | 桌面与手机保留展开历史、全屏、Escape 返回和独立内容滚动；正文、公式和表格均可读 |

首屏文案核对：除用户授权去掉的重复栏目标题、素材入口明确为“添加素材”、以及功能性的图表展开/收起操作，其余采用现有页面文案与实际数据。参考图生成的示例问题、假累计量及不存在的附件功能不会出现在产品中。验证用的示例题目只存在于浏览器拦截层。

有意差异：正文按真实资料长度自然流动，不强行凑参考图的行数；聊天沿用已有会话管理与发送功能；手机及小窗口的图表默认状态以阅读效率为先。其余排版、字体、色彩、间距、图片边缘及响应式修正已核对；未保留待修复的视觉或交互问题。

## 验证

- Vue / TypeScript 类型检查和生产构建通过。
- 5 项已有单元测试通过。
- 5 项完整浏览器集成场景通过：会话保存与管理、Markdown 与公式、录题/编辑/复习/资料保存、模型切换、时政标签与各页可视化。真实写入使用随机隔离 schema，脚本自动清理。
- 全站只读检查覆盖 78 个页面/尺寸组合，包含 14 个入口及已有内容的详情路线，没有横向溢出、聊天外层纵向溢出、非预期 API 错误或页面脚本异常。
- 最终调整后单独复查 30 个手机与深色页面/尺寸组合，等待路由实际挂载后检查，未发现空白页面或溢出。
- 另用浏览器拦截数据复核 28 个有内容的页面/尺寸组合，验证 11 条流程：错题搜索、题型筛选、录入、编辑、复习答题、完成复习、弹窗 Escape 与焦点恢复、词语收藏与掌握标记、申论提纲及保存。没有向实际资料库写入测试内容。
- 手机筛选器最终样式另检查 760、390、320px 及详情，共 5 个组合，无脚本异常与溢出。
- 保留键盘焦点、原生弹窗焦点约束、密码显示状态、辅助技术标题、当前导航和减少动态效果偏好。

前端设计版本已于 2026-10-05 部署至 [服务器 HTTPS 入口](https://175.24.234.152:9443)。Docker 构建包含自托管字体与插画；首轮公网验收覆盖桌面、手机共 28 个页面组合，当批全部 96 个发布文件的校验和与镜像一致。登录、会话续期、退出和主题切换通过，未发现脚本异常、资源错误或横向溢出。首轮部署、备份与回滚记录见 [前端发布记录](frontend-deployment-2026-10-05.md)。本地 5174 仍可用于开发预览。构建仍有既有 ECharts 分包超过 500 kB 的提示。

同日新增自定义模型接入，沿用宋体标题、白色弹窗、淡蓝默认模型区域及开放内容行，入口与顶部快捷模型切换融合。支持提供商、Base URL、API Key、模型名称及 JSON 模式，密钥保存后不回显。该功能及对应服务已同步上线，桌面、390px/320px 手机与深色界面通过实际浏览器验收，当批 94 个发布文件与镜像一致。接入说明见 [模型接入](ai-provider.md)。
